stackrun

v{{VERSION}} · {{REPO}}

Process-orchestration CLI. Run one or more OS commands at the same time, with prefixed logs, lifecycle hooks, and optional Cloudflare tunnels.

Install from GitHub Releases

No Rust or Node. Detects OS/arch, checks SHA256SUMS, installs to ~/.local/bin.

curl -fsSL https://jasenmichael.github.io/stackrun/install.sh | sh

Pin a version or install directory: 

curl -fsSL https://jasenmichael.github.io/stackrun/install.sh | STACKRUN_VERSION={{VERSION}} sh
curl -fsSL https://jasenmichael.github.io/stackrun/install.sh | STACKRUN_INSTALL=/usr/local/bin sh

Manual archives and checksums: GitHub Releases. Windows: download x86_64-pc-windows-msvc zip.

crates.io

Needs cargo because cargo builds the crate.

cargo install stackrun

npm

Needs Node. Also provides import { stackrun }.

npx stackrun
npm i -g stackrun
npm i -D stackrun

From source

Needs a Rust stable toolchain (rust-toolchain.toml pins stable).

git clone https://github.com/{{REPO}}
cd stackrun
cargo install --path .
